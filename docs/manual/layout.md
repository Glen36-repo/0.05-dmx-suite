# Light layout and groups

## The layout

The Live page shows every light as a square in its live colour; a pixel bar shows each pixel. Where they sit comes from the **Layout** page.

To arrange them:

1. Pick lights: tap one (shift-tap to add more), drag a box round several, use **Lasso** to draw round them, or tap a group tab. Ctrl+A picks everything; Esc picks nothing.
2. Use **Move** and drag them to where they really are.
3. Tidy up with **Left / Centre / Right / Top / Middle / Bottom**, **Space across / down**, **Make a row / ring / grid**, or rotate by 45°.
4. For a pixel bar, **Pixels: in a row / ring / grid** changes how its pixels are drawn.
5. **Undo** steps back (Ctrl+Z); **Undo all changes** goes back to what's saved. **Save layout** writes it to the rig file.

**Beams** shows where each moving head points. **Names** shows or hides the labels; **Zoom** makes the layout bigger.

## Groups

Groups are names for sets of lights (bars, front, movers); scenes and drum flashes use them.

- **New group from selection:** pick lights, type a name, press the button.
- **Set group to selection:** open the group's tab, change the selection, press the button.
- **Rename group:** open its tab, type the new name. Every scene, look, rig and MIDI map using the old name is changed with it.
- **Delete group:** refused while a scene or MIDI map still uses it.

A group name can't be a light's name, a kind of light (head, bar, wash, kick, haze) or "all".

## Theme

Setup page, **Appearance**: Neutral or 0.05. Each laptop remembers its own choice.
