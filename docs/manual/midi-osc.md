# MIDI and OSC

The MIDI map (`midi/default.yaml`) says what each program change, note or CC does: pick a show or set, MASTER, blackout, flash lights from a drum pad, move a fader, haze.

**MIDI learn:** on the MIDI tab, pick an action, then press the pedal or hit the pad. Save keeps the previous map in `.backups`.

A mapping can be tied to one interface (`port:`), so two devices can use the same note numbers.
