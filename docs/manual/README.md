# 0.05 DMX Suite user manual

Live lighting for Windows: build scenes and shows, run them from MIDI or OSC, and send DMX to your lights. Everything can be done on screen; Claude is an optional helper.

Pages are filled in as each release lands (v2, then v3). Where a page says "coming" or names a later v3 release, that part isn't built yet.

1. [Getting started](getting-started.md): install, first run, the simulator
2. [Fixtures and rigs](fixtures.md): the setup wizard, adding lights, fixture types, rig settings, rule profiles
3. [Light layout and groups](layout.md): arranging the lights on screen, making groups
4. [Scenes](scenes.md): colours, effects, positions, layers
5. [Shows and setlists](shows.md): steps, repeats, fades, auto shows, setlists
6. [Busking](busking.md): live buttons and faders
7. [MIDI and OSC](midi-osc.md): named inputs and devices, mapping pedals, drums and controllers
8. [Moving heads and head points](heads.md): aiming heads, named points per rig
9. [Colours and palettes](palettes.md): the colour wheel, named colours, palettes
10. [Safety and troubleshooting](troubleshooting.md): the safety rules, alerts, when something goes wrong
